# 模块新增

- 名称：模块新增
- 描述：在问卷下新建模块
- 路径：`/api/questionnaires/:questionnaireUuid/modules`
- 请求方法：POST

## 入参

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `questionnaireUuid` | string | 是 | 问卷 uuid |
| `name` | string | 是 | 去空白后不能为空 |

```json
{
  "name": "基础信息"
}
```

## 出参

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data.uuid` | string | 新建模块的 uuid |

HTTP 201：

```json
{
  "success": true,
  "data": {
    "uuid": "3f2a1b0c-4d5e-6f70-8192-a3b4c5d6e7f8"
  }
}
```

| HTTP | errorKey | errorMessage |
| --- | --- | --- |
| 400 | `questionnaire:errors.required` | 请检查必填字段 |
| 404 | `questionnaire:errors.questionnaire` | 问卷不存在 |

名称为空时，HTTP 400：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.required",
  "errorMessage": "请检查必填字段"
}
```

问卷不存在时，HTTP 404：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.questionnaire",
  "errorMessage": "问卷不存在"
}
```
