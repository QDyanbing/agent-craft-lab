# 模块修改

- 名称：模块修改
- 描述：修改模块名称
- 路径：`/api/questionnaires/:questionnaireUuid/modules/:moduleUuid`
- 请求方法：PUT

## 入参

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `questionnaireUuid` | string | 是 | 问卷 uuid |
| `moduleUuid` | string | 是 | 模块 uuid |
| `name` | string | 是 | 去空白后不能为空 |

```json
{
  "name": "课程"
}
```

## 出参

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data` | null | 修改成功 |

```json
{
  "success": true,
  "data": null
}
```

| HTTP | errorKey | errorMessage |
| --- | --- | --- |
| 400 | `questionnaire:errors.required` | 请检查必填字段 |
| 404 | `questionnaire:errors.record` | 记录不存在 |

名称为空时，HTTP 400：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.required",
  "errorMessage": "请检查必填字段"
}
```

模块不存在时，HTTP 404：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.record",
  "errorMessage": "记录不存在"
}
```
