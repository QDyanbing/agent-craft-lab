# 题目删除

- 名称：题目删除
- 描述：删除题目，并去掉该题已保存的答案
- 路径：`/api/questionnaires/:questionnaireUuid/modules/:moduleUuid/questions/:questionUuid`
- 请求方法：DELETE

## 入参

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `questionnaireUuid` | string | 是 | 问卷 uuid |
| `moduleUuid` | string | 是 | 模块 uuid |
| `questionUuid` | string | 是 | 题目 uuid |

## 出参

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data` | null | 删除成功 |

```json
{
  "success": true,
  "data": null
}
```

| HTTP | errorKey | errorMessage |
| --- | --- | --- |
| 404 | `questionnaire:errors.module` | 模块不存在 |
| 404 | `questionnaire:errors.record` | 记录不存在 |

模块不存在时，HTTP 404：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.module",
  "errorMessage": "模块不存在"
}
```

题目不存在时，HTTP 404：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.record",
  "errorMessage": "记录不存在"
}
```
