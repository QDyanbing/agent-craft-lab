# 题目修改

- 名称：题目修改
- 描述：修改题目
- 路径：`/api/questionnaires/:questionnaireUuid/modules/:moduleUuid/questions/:questionUuid`
- 请求方法：PUT

## 入参

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `questionnaireUuid` | string | 是 | 问卷 uuid |
| `moduleUuid` | string | 是 | 模块 uuid |
| `questionUuid` | string | 是 | 题目 uuid |
| `type` | `SINGLE` \| `MULTIPLE` \| `TEXT` \| `NUMBER` | 是 | 题目类型 |
| `title` | string | 是 | 去空白后不能为空 |
| `description` | string | 否 | 省略后为空字符串 |
| `options` | string[] | `SINGLE`、`MULTIPLE` 必填 | 选项 |

```json
{
  "type": "MULTIPLE",
  "title": "兴趣",
  "description": "选择兴趣",
  "options": ["阅读", "跑步", "音乐"]
}
```

## 出参

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data` | null | 修改成功 |

```json
{
  "success": true,
  "data": null
}
```

| HTTP | errorKey | errorMessage |
| --- | --- | --- |
| 400 | `questionnaire:errors.required` | 请检查必填字段 |
| 400 | `questionnaire:errors.type` | 无效的题目类型 |
| 400 | `questionnaire:errors.options` | 请添加选项 |
| 404 | `questionnaire:errors.module` | 模块不存在 |
| 404 | `questionnaire:errors.record` | 记录不存在 |

标题为空时，HTTP 400：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.required",
  "errorMessage": "请检查必填字段"
}
```

`type` 不是 `SINGLE`、`MULTIPLE`、`TEXT`、`NUMBER` 时，HTTP 400：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.type",
  "errorMessage": "无效的题目类型"
}
```

单选或多选没有选项时，HTTP 400：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.options",
  "errorMessage": "请添加选项"
}
```

模块不存在时，HTTP 404：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.module",
  "errorMessage": "模块不存在"
}
```

题目不存在时，HTTP 404：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.record",
  "errorMessage": "记录不存在"
}
```
