# 题目答题

- 名称：题目答题
- 描述：保存一道题的答案
- 路径：`/api/questionnaires/:questionnaireUuid/modules/:moduleUuid/questions/:questionUuid/answer`
- 请求方法：POST

## 入参

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `questionnaireUuid` | string | 是 | 问卷 uuid |
| `moduleUuid` | string | 是 | 模块 uuid |
| `questionUuid` | string | 是 | 题目 uuid |
| `answer` | number \| number[] \| string | 是 | `SINGLE` 为选项下标；`MULTIPLE` 为下标数组；`TEXT` 为非空字符串；`NUMBER` 为有限数字 |

```json
{
  "answer": 0
}
```

```json
{
  "answer": [0, 1]
}
```

```json
{
  "answer": "我的答案"
}
```

```json
{
  "answer": 3.5
}
```

## 出参

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data.uuid` | string | 答卷 uuid |

HTTP 201：

```json
{
  "success": true,
  "data": {
    "uuid": "c3d4e5f6-a7b8-9012-cdef-123456789012"
  }
}
```

| HTTP | errorKey | errorMessage |
| --- | --- | --- |
| 400 | `questionnaire:errors.form` | 无效的表单 |
| 400 | `questionnaire:errors.answer` | 请检查答案的题型和选项 |
| 404 | `questionnaire:errors.questionnaire` | 问卷不存在 |
| 404 | `questionnaire:errors.module` | 模块不存在 |
| 404 | `questionnaire:errors.record` | 记录不存在 |

字段缺失或类型不对时，HTTP 400：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.form",
  "errorMessage": "无效的表单"
}
```

答案和题型对不上时，HTTP 400：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.answer",
  "errorMessage": "请检查答案的题型和选项"
}
```

问卷不存在时，HTTP 404：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.questionnaire",
  "errorMessage": "问卷不存在"
}
```

模块不存在时，HTTP 404：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.module",
  "errorMessage": "模块不存在"
}
```

题目不存在时，HTTP 404：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.record",
  "errorMessage": "记录不存在"
}
```
