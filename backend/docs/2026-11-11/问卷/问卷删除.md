# 问卷删除

- 名称：问卷删除
- 描述：删除问卷，并连带删除其模块、题目和答卷
- 路径：`/api/questionnaires/:questionnaireUuid`
- 请求方法：DELETE

## 入参

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `questionnaireUuid` | string | 是 | 问卷 uuid |

## 出参

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data` | null | 删除成功 |

```json
{
  "success": true,
  "data": null
}
```

| HTTP | errorKey | errorMessage |
| --- | --- | --- |
| 404 | `questionnaire:errors.record` | 记录不存在 |

问卷不存在时，HTTP 404：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.record",
  "errorMessage": "记录不存在"
}
```
