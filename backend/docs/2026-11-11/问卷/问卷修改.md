# 问卷修改

- 名称：问卷修改
- 描述：修改问卷名称和描述
- 路径：`/api/questionnaires/:questionnaireUuid`
- 请求方法：PUT

## 入参

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `questionnaireUuid` | string | 是 | 问卷 uuid |
| `name` | string | 是 | 去空白后不能为空，不区分大小写唯一 |
| `description` | string | 否 | 省略后为空字符串 |

```json
{
  "name": "调查",
  "description": "学习情况"
}
```

## 出参

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data` | null | 修改成功 |

```json
{
  "success": true,
  "data": null
}
```

| HTTP | errorKey | errorMessage |
| --- | --- | --- |
| 400 | `questionnaire:errors.required` | 请检查必填字段 |
| 404 | `questionnaire:errors.record` | 记录不存在 |
| 409 | `questionnaire:errors.duplicateName` | 问卷名称已存在，请换一个名称 |

名称为空时，HTTP 400：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.required",
  "errorMessage": "请检查必填字段"
}
```

问卷不存在时，HTTP 404：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.record",
  "errorMessage": "记录不存在"
}
```

名称已存在时，HTTP 409：

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.duplicateName",
  "errorMessage": "问卷名称已存在，请换一个名称"
}
```
