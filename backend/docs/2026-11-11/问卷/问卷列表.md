# 问卷列表

- 名称：问卷列表
- 描述：按名称或描述查询问卷
- 路径：`/api/questionnaires`
- 请求方法：GET

## 入参

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `keyword` | string | 否 | 匹配名称或描述，忽略大小写。空字符串表示不过滤 |
| `pageNum` | number | 是 | 页码，从 1 开始 |
| `pageSize` | number | 是 | 每页条数，默认 10，大于等于 1 |

```json
{
  "keyword": "调查",
  "pageNum": 1,
  "pageSize": 10
}
```

## 出参

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data.list` | array | 当前页 |
| `data.list[].uuid` | string | 问卷 uuid |
| `data.list[].name` | string | 名称 |
| `data.list[].description` | string | 描述 |
| `data.list[].moduleCount` | number | 模块数 |
| `data.list[].questionCount` | number | 题目数 |
| `data.total` | number | 过滤后的总数 |

```json
{
  "success": true,
  "data": {
    "list": [
      {
        "uuid": "9b1deb4c-2b0a-4c1e-9f3a-6d8e0a1b2c3d",
        "name": "调查",
        "description": "学习情况",
        "moduleCount": 1,
        "questionCount": 2
      }
    ],
    "total": 1
  }
}
```

缺少 `pageNum` 或 `pageSize`，或数值小于 1 时：

| HTTP | errorKey | errorMessage |
| --- | --- | --- |
| 400 | `questionnaire:errors.pagination` | 无效的分页参数 |

```json
{
  "success": false,
  "errorKey": "questionnaire:errors.pagination",
  "errorMessage": "无效的分页参数"
}
```
