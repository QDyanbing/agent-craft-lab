# 表结构

- 库名：`craft_lab`
- 文件：`data/questionnaires.sqlite`
- 引擎：SQLite，`user_version` 为 12，连接时 `PRAGMA foreign_keys = ON`

## craft_lab_questionnaires

- 表名：`craft_lab_questionnaires`
- 说明：问卷

| 字段名 | 类型 | 为空 | 默认值 | 键 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `uuid` | TEXT | 否 | | 主键 | 问卷 uuid |
| `name` | TEXT | 否 | | | 名称 |
| `description` | TEXT | 否 | | | 描述，可以是空字符串 |
| `gmt_created` | TEXT | 否 | `CURRENT_TIMESTAMP` | | 创建时间，UTC，形如 `YYYY-MM-DD HH:MM:SS` |
| `gmt_modified` | TEXT | 否 | `CURRENT_TIMESTAMP` | | 更新时间，UTC，形如 `YYYY-MM-DD HH:MM:SS` |

| 索引名 | 字段 | 类型 |
| --- | --- | --- |
| `craft_lab_questionnaires_unique_name` | `name COLLATE NOCASE` | 唯一 |

## craft_lab_modules

- 表名：`craft_lab_modules`
- 说明：模块

| 字段名 | 类型 | 为空 | 默认值 | 键 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `uuid` | TEXT | 否 | | 主键 | 模块 uuid |
| `questionnaire_uuid` | TEXT | 否 | | 外键 | 问卷 uuid，引用 `craft_lab_questionnaires.uuid`，删除问卷时级联删除 |
| `name` | TEXT | 否 | | | 模块名称 |
| `gmt_created` | TEXT | 否 | `CURRENT_TIMESTAMP` | | 创建时间，UTC，形如 `YYYY-MM-DD HH:MM:SS` |
| `gmt_modified` | TEXT | 否 | `CURRENT_TIMESTAMP` | | 更新时间，UTC，形如 `YYYY-MM-DD HH:MM:SS` |

| 索引名 | 字段 | 类型 |
| --- | --- | --- |
| `craft_lab_modules_questionnaire_uuid` | `questionnaire_uuid` | 普通 |

## craft_lab_questions

- 表名：`craft_lab_questions`
- 说明：题目

| 字段名 | 类型 | 为空 | 默认值 | 键 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `uuid` | TEXT | 否 | | 主键 | 题目 uuid |
| `module_uuid` | TEXT | 否 | | 外键 | 模块 uuid，引用 `craft_lab_modules.uuid`，删除模块时级联删除 |
| `type` | TEXT | 否 | | | `SINGLE`、`MULTIPLE`、`TEXT`、`NUMBER` |
| `title` | TEXT | 否 | | | 标题 |
| `description` | TEXT | 否 | | | 描述，可以是空字符串 |
| `options` | TEXT | 否 | | | 选项。`TEXT`、`NUMBER` 为 `[]` |
| `gmt_created` | TEXT | 否 | `CURRENT_TIMESTAMP` | | 创建时间，UTC，形如 `YYYY-MM-DD HH:MM:SS` |
| `gmt_modified` | TEXT | 否 | `CURRENT_TIMESTAMP` | | 更新时间，UTC，形如 `YYYY-MM-DD HH:MM:SS` |

| 索引名 | 字段 | 类型 |
| --- | --- | --- |
| `craft_lab_questions_module_uuid` | `module_uuid` | 普通 |

## craft_lab_answer

- 表名：`craft_lab_answer`
- 说明：一道题的答案。删除题目时级联删除。修改题目类型或选项时删除本行

| 字段名 | 类型 | 为空 | 默认值 | 键 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `uuid` | TEXT | 否 | | 主键 | 答案 uuid |
| `question_uuid` | TEXT | 否 | | 外键、唯一 | 题目 uuid，引用 `craft_lab_questions.uuid`，一道题一行 |
| `answer` | TEXT | 否 | | | 答案。`SINGLE` 为选项下标；`MULTIPLE` 为下标数组；`TEXT` 为字符串；`NUMBER` 为数字 |
| `gmt_created` | TEXT | 否 | `CURRENT_TIMESTAMP` | | 创建时间，UTC，形如 `YYYY-MM-DD HH:MM:SS` |
| `gmt_modified` | TEXT | 否 | `CURRENT_TIMESTAMP` | | 更新时间，UTC，形如 `YYYY-MM-DD HH:MM:SS` |
